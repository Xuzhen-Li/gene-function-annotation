# 交接指针 — 结构 → 功能

英文卡片：[`../HANDOFF_STRUCTURE_TO_FUNCTION.md`](../HANDOFF_STRUCTURE_TO_FUNCTION.md)。

从结构放行拷进本仓 `local.env`：

1. **`RELEASE_TAG`** = 结构 `release/<TAG>/` 同名  
2. **`PROTEINS_FA`** = `…/release/<TAG>/proteins.faa`（稳定别名；勿用过期根副本）  
3. **`structure_grade`** = 诚实的结构档位（临时 GFF 勿自称 F-L1）
