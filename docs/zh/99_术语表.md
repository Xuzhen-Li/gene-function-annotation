# 术语表（功能注释教学）

| 术语 | 含义 |
|------|------|
| **PROTEINS_FA** | 输入代表蛋白 FASTA（通常一基因一条） |
| **F0** | 蛋白 BUSCO 健全性检查 |
| **F1** | 默认框：DIAMOND + eggNOG-mapper + InterProScan |
| **F2 / F3 / F5** | 替代框：快 emapper / EnTAP / Trinotate |
| **F4 / F6 / F7 / F8 / F9** | **加件**：AHRD / Mercator / OrthoFinder / NLR / iTAK（≠ Gate-F*） |
| **脚本 `F2_eggnog.sh`** | 框架 F1 内的 eggNOG 步（历史文件名）；**≠ 快框框架 F2** |
| **TOOLS F1a/b/c** | 同上三步素养页（F1b=eggNOG） |
| **Gate-F1…Gate-F7** | 放行**硬门槛**（provenance / BUSCO / 版本 / 行数 / 卫生…）；口播必须写全称 **Gate-F***，勿缩「门 F*」 |
| **Gate-F1 ≠ 框架 F1** | Gate=门槛条目；框架=声明的整套方法 |
| **Gate-F4 ≠ 加件 F4** | Gate-F4=版本钉死；F4=AHRD |
| **Gate-F7 ≠ 加件 F7** | Gate-F7=无私有库进仓；F7=OrthoFinder |
| **DIAMOND** | 快速蛋白比对；本仓常打 Swiss-Prot |
| **Swiss-Prot** | UniProt 精标子集；同源线索用 |
| **eggNOG-mapper (emapper)** | 基于 eggNOG 的直系同源功能转移 |
| **InterProScan (IPS)** | 整合多成员库的结构域/签名扫描 |
| **functional_master.tsv** | 基因中心总表；本仓真相来源 |
| **AHRD** | 从证据选可读英文描述 |
| **Mercator4 / MapMan** | 植物 BIN / 通路注释体系 |
| **KofamScan** | KEGG KO 阈值扫描（可选） |
| **F-L0 / F-L1** | 功能验收**档位**（写 `grade=F-L0|F-L1`） |
| **grade vs status** | grade=F-L0/F-L1；status 只写 provisional/qualified；**勿**写 status=F-L1 |
| **provenance** | 蛋白来自哪个结构 `RELEASE_TAG` 或哈希 |
| **税域 tax_scope** | emapper 限制直系同源搜索的分类范围 |
| **CAFA** | GO 预测竞赛基准；**不是**本仓放行标准 |
| **print-first** | 助手先打印命令；`RUN=1` 才执行 |
| **GFF 第 9 列写回** | 把 GO 等写入 GFF 属性 — **本仓尚未宣称自动完成** |

英文操作以 [`../EVALUATION.md`](../EVALUATION.md)、[`../ROADMAP.md`](../ROADMAP.md)、[`../INSTALL_FUNCTIONAL.md`](../INSTALL_FUNCTIONAL.md) 为准。
