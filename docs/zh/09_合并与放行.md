## Merge：真相在总表

```text
diamond/swissprot.tsv
eggnog|emapper annotations
interpro/*.tsv
（可选 ahrd / mercator / nlr / itak）
        │
        ▼
F_merge_tables.py
        │
        ▼
function/merge/functional_master.tsv
```

规则：

1. **一行一基因**（或与 isoform 政策一致）。  
2. 行数 ≈ 输入蛋白数；掉行、重复 ID 必须记载。  
3. 原始 `diamond/`、`interpro/` 目录是中间体，**不是**放行产物。  
4. **不宣称**自动写回 GFF 第 9 列 — 总表才是 source of truth。

## Release 包

```bash
bash pipeline/F_release.sh
# → function/release/<TAG>/
#    master TSV + proteins 副本 + METHODS stub
```

METHODS stub 里填：工具与 DB 版本、结构 `RELEASE_TAG`、用了哪些加件（或标明 unused）。

## 卫生

不要把 Swiss-Prot / eggNOG 整库、私有 BAM/FASTQ 推进 git 或 release tarball。DB 用版本号 + URL 引用。
