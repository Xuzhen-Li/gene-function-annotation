# 常见翻车（功能注释）

对照 [`../EVALUATION.md`](../EVALUATION.md) 自动不合格条款。

## 为什么单独设「翻车课」？

1. FA 事故高度重复：版本错配、无 provenance、假 CAFA、坏结构装饰。  
2. 每条对应 WHY 深课与 EVALUATION 自动不合格条款。  
3. 反例比门禁条文更好记。  
4. 提醒：本仓不改外显子。  
5. 与 [13](13_为什么F1是三件套.md)–[15](15_为什么版本和谱系必须写清.md) 互链。

**反例：** 注释全空只知道「重跑」，不查 mapper/DB 配对。
## 1. Mapper / DB 版本错配

**现象：** 注释几乎全空，或列含义对不上。  
**典型：** eggNOG-mapper v3 配 eggNOG **v5** 库。  
**处理：** 查 INSTALL 与 emapper 文档的官方配对；METHODS 写两侧版本。

## 2. 宣称 CAFA 级 GO 精度

DIAMOND/emapper 是同源/直系同源**转移**，不是 CAFA 竞赛提交。METHODS 写「transferred from…」，别写「we achieved CAFA Fmax…」。

## 3. 没有蛋白来源（无 provenance）

匿名 `proteins.faa`、结构改过两轮却不更新 TAG → 功能表与基因模型对不上账。Gate-F1 直接失败。

## 4. 用 FA 遮羞坏结构

TE 假基因、串联塌缩、错剪接上贴满 GO — 看起来很勤快，科学上更糟。F0 灾难必须回结构。

## 5. 把替代框标成 F1

EnTAP / Trinotate / 纯 emapper 快框各有误差模式。框名写错会害 meta 分析与审稿。

## 6. 只丢原始 diamond/ 文件夹当「放行」

没有 merge 总表、没有 METHODS、没有 TAG 目录 → Gate-F6 失败。

## 7. 暗示跑了没跑的加件

「做了 MapMan / NLR / iTAK」但目录空着 — 审稿人对照文件一目了然。不用就写 unused。

## 8. ID 对不齐

FASTA 头与 emapper/IPS 第一列不一致 → merge 掉行或错行。先统一 gene id。

## 9. 把巨型 DB 推进 git

Swiss-Prot / eggNOG / InterPro 数据目录进仓库 — 卫生Gate-F7 失败，也撑爆远程。

## 10. 指望功能仓改外显子

错坐标回结构仓 GSAman；本仓不策展 exon。
