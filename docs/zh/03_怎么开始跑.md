# 怎么开始跑（功能注释）

> 与中文首页「今天最短路径」一致。没有 `proteins.faa` 先回结构仓。


1. 确认已有结构放行的 `proteins.faa`（写清 `RELEASE_TAG` 或哈希）。  
2. flow 工具选 F 框并生成讲解计划：

```bash
git clone https://github.com/Xuzhen-Li/gene-function-annotation.git
cd gene-function-annotation
cp pipeline/flow_tool/answers.example.yaml my_answers.yaml
python3 pipeline/flow_tool/flow.py --answers my_answers.yaml -o my_fa_plan.md
```

3. [`../INSTALL_FUNCTIONAL.md`](../INSTALL_FUNCTIONAL.md) 装库 → 按 plan 跑 → [`../EVALUATION.md`](../EVALUATION.md) 勾 F-L1。

```bash
cp config/example.env config/local.env
# PROTEINS_FA、DIAMOND_DB、EGGNOG_*、BUSCO_LINEAGE_PROTEIN、FUNCTION_DIR、RELEASE_TAG…
set -a && source config/local.env && set +a
mkdir -p "$FUNCTION_DIR"/{diamond,eggnog,interpro,merge,qc,release}
```

拿不准 → **F1**（DIAMOND + eggNOG + InterProScan）。助手多半 print-first：`RUN=1` 才真正执行。

## 为什么

1. 没有稳定 `proteins.faa`（带来源）就开跑 = 无 provenance。  
2. flow 先选框，避免 F2 快框冒充 F1。  
3. `local.env` 钉 DB 路径与谱系，复现靠它。  
4. Print-first（`RUN=1`）防止在错路径上烧 IPS。  
5. 拿不准 → **F1** 三件套。

**反例：** 复制同事的 Swiss-Prot 路径，实际指向过期或空文件。
