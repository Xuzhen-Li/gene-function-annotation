# 替代框架：F2 / F3 / F5

这些是**换主框**，不是 F1 的小插件。用了必须在 METHODS 写框名；**禁止**把 EnTAP/Trinotate 输出标成「F1」。

英文：[`../ROADMAP.md`](../ROADMAP.md) · [`../RELATED_SOFTWARE.md`](../RELATED_SOFTWARE.md)

## F2 — 快框（emapper 为主）

| | |
|--|--|
| **何时** | 今天就要答案；InterProScan 太慢 |
| **核心** | eggNOG-mapper（± Kofam `F1b`） |
| **等级** | 通常 **F-L0**，除非日后把 IPS 补进 merge 并达到 F-L1 |
| **诚实** | 写明「IPS deferred」 |

## F3 — EnTAP 中心实验室

| | |
|--|--|
| **何时** | 组内已标准化 EnTAP（配置/库都在） |
| **做法** | 按 EnTAP 文档跑 → 把终表拷进 `function/entap/` → 并入 master |
| **注意** | EnTAP 可把 IPS 当可选；若你跳过 IPS，按 F-L0 或写明 waiver |

## F5 — Trinotate（转录组 CDS）

| | |
|--|--|
| **何时** | Trinity/TransDecoder 肽段，尚无基因组 GFF |
| **角色** | 转录组功能草表；基因组蛋白出来后应重跑 F1 |
| **不是** | 植物基因组论文的默认主框 |

## 怎么选（一眼）

```text
正常基因组蛋白、要发表     → F1
今天就要、IPS 排不上       → F2，日后再并 IPS
实验室绑定 EnTAP           → F3
只有转录组肽段             → F5
```
