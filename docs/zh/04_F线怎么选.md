命名易混：脚本 `F2_eggnog.sh` 有两种角色。  
在框架 F1 里，它是 eggNOG 那一步。  
在快框 F2 里，它是主引擎。同一文件，靠你声明的框区分。

拿不准 → **F1**。

## 为什么

1. **主干 / 替代框 / 加件**误差模式不同，METHODS 框名必须诚实。  
2. 加件不能单独抬高 F-L1。  
3. 脚本名 `F2_eggnog.sh` 一身二职 — 角色靠你声明的框。  
4. 今天就要且 IPS 排不上 → F2，但通常 F-L0。  
5. 拿不准 → F1，降低框架混乱。

**反例：** EnTAP 输出写成「F1 DIAMOND+eggNOG+IPS」。
