# Contributing

Short rules for this repo (function / F1). English public surfaces only.

## Classroom vs cluster

- **Classroom** = `my_fa_plan` / print-first. Finish the plan; do **not** invent `status=F-L1` or fake L1.
- `grade=` and `status=` are separate fields.

## Boundaries

- **TE soft-mask is hard** and lives in structure (A0 / trusted lib). This repo does **not** soft-mask or edit GFF.
- **FA only here** — GO/KEGG/names/domains after proteins exist.
- Structure is primary; handoff via PROTEINS_FA / TAG. See [`docs/BOUNDARY.md`](docs/BOUNDARY.md) (points to the three-layer map).

## How to work

- Use the [issue templates](.github/ISSUE_TEMPLATE/); open a PR with the checklist.
- Track work on [Annotation Project #2](https://github.com/users/Xuzhen-Li/projects/2).
- Public English. Chinese teaching stays under `docs/zh/` only.
