# 验收：F-L0 / F-L1

**先打勾：** [验收勾选表.md](验收勾选表.md)（一行页，判断行不行）。

**权威条文：** 英文 [`../EVALUATION.md`](../EVALUATION.md)。本页中文讲门禁意图。

## 为什么

1. F-L0 / F-L1 分开，避免快框洗白成论文骨架。  
2. 硬门槛（**Gate-F***，勿与 frame F1 / 脚本 F2 混号）抓住 provenance、谱系、三件套、版本、行数、卫生。  
3. 软指标按谱系解读 — 植物离 Swiss-Prot 远不等于失败。  
4. 自动不合格条款对准假 F1、DB 错配、假 CAFA、无 TAG。  
5. 跨层：结构未合格 → FA 不能假装合格。

**反例：** 无结构 RELEASE_TAG 的蛋白集冲 F-L1。  

深课：[15_为什么版本和谱系必须写清.md](15_为什么版本和谱系必须写清.md)

## 两档

| 等级 | 标签 | 何时 |
|------|------|------|
| **F-L0 Slim** | provisional 或 `frame=F2/F3/F5` | 快框、IPS 延期、merge 未完 |
| **F-L1 Qualified** | `status=qualified` | 下列硬门槛全过 — 默认论文 FA |

植物加件（F4/F6/F8/F9）**不是**更高一档，只是 METHODS 模块。

## F-L1 硬门槛

| 门 | 在考什么 |
|----|----------|
| **Gate-F1** | `PROTEINS_FA` 有来源（结构 TAG 或哈希） |
| **Gate-F2** | F0 蛋白 BUSCO：Completeness + **谱系**；灾难则先修结构 |
| **Gate-F3** | 默认 **frame F1** 三件套，或书面 waiver 点名 frame F2/F3/F5 |
| **Gate-F4** | 工具 + DB 版本钉死 |
| **Gate-F5** | master 行数 ≈ 蛋白数；掉行有说明 |
| **Gate-F6** | `release/<TAG>/` 含 master + 蛋白副本 + METHODS |
| **Gate-F7** | 无私有 reads / 多 GB DB 进仓 |

## 软指标

命中率、域覆盖、AHRD/Mercator 是否使用 — 按谱系解读。植物离 Swiss-Prot 远，命中率「难看」不一定是失败。  
**不宣称：** CAFA 级 GO 精度；自动写 GFF 第 9 列。

## 自动不合格

- 把 EnTAP/Trinotate/TransAnnot 输出标成 F1 却不写替代框  
- emapper v3 + eggNOG v5（或明显 mapper/DB 错配）却不声明  
- 仅靠 blast 转移就宣称 CAFA 式 GO 精度  
- FA 放行依赖无 TAG/哈希的结构蛋白

## 跨层

```text
结构 L1/L2  →  proteins  →  FA F-L1
结构 L0     →  FA 只能暂定
F0 灾难     →  停 FA，回结构
```
