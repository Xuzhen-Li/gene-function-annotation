# 和结构注释的关系

两层（教学常用说法，与 Ji *Nat Rev Genet* 2026 一致）：

```text
结构：基因在哪（坐标）     →  GFF + proteins
功能：蛋白像什么（标签）   →  master TSV
```

## 为什么

1. 坐标错了，标签再全也是错对象上的正确词。  
2. **Provenance**（结构 TAG）让两层可对账。  
3. F0 是花费闸：灾难蛋白集不值得开 IPS。  
4. 结构 L0 → FA 只能暂定，避免等级洗白。  
5. 策展外显子回结构仓，不在本仓「用 GO 修好」。

**反例：** 功能表很漂亮，用来证明「结构应该没问题」。  

深课：[14_为什么先结构后功能.md](14_为什么先结构后功能.md)
规则：

1. **先结构后功能。** 结构是 L0 暂定，功能也只能当暂定。  
2. **F0 蛋白 BUSCO 崩了** → 停功能，回结构修。  
3. 功能表再漂亮，也**救不了**错误位点、TE 假基因、塌缩的串联家族。  
4. METHODS 写明 `PROTEINS_FA` 来自哪个结构 `RELEASE_TAG`（或外部哈希）— 两层靠这个对账。
