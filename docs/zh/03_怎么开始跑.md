# 怎么开始跑（功能注释）

> 与中文首页「今天最短路径」一致。没有 `proteins.faa` 先回结构仓。


1. 确认已有结构放行的 `proteins.faa`（写清 `RELEASE_TAG` 或哈希）。  
2. flow 工具选 F 框并生成讲解计划：

```bash
git clone https://github.com/Xuzhen-Li/gene-function-annotation.git
cd gene-function-annotation
cp pipeline/flow_tool/answers.example.yaml my_answers.yaml
python3 pipeline/flow_tool/flow.py --answers my_answers.yaml -o my_fa_plan.md
```

3. **课堂默认可停：** 读懂 `my_fa_plan.md` + [FAQ 编号对照](FAQ_入门.md) + 列出将需要的 `PROTEINS_FA`/DB 磁盘路径（不必当晚装完 IPS）。  

4. **有环境再冲：** [`../INSTALL_FUNCTIONAL.md`](../INSTALL_FUNCTIONAL.md) 装库 → `RUN=1` 按 plan 跑框架 F1 → [`../EVALUATION.md`](../EVALUATION.md) / 勾选表认 **F-L1**（档位目标，不是「今晚必须交满跑」）。


```bash
cp config/example.env config/local.env
# ★ 先把 local.env 里所有 /path/to 改成真实盘（PROTEINS_FA、WORK_DIR、FUNCTION_DIR、DB…）
#   未改就 source：mkdir 会 Permission denied
set -a && source config/local.env && set +a
case "$WORK_DIR" in /path/to*|*/path/to*) echo "先改 WORK_DIR，不要照抄 /path/to"; exit 1;; esac
case "$FUNCTION_DIR" in /path/to*|*/path/to*) echo "先改 FUNCTION_DIR"; exit 1;; esac
mkdir -p "$FUNCTION_DIR"/{diamond,emapper,interpro,merge,qc,release}
```

`print_qc`：可先 `python3 pipeline/print_qc_commands.py --env config/example.env` 空看样例——**此时出现 `[STOP]` 属预期（占位/`YOUR_*`），不是坏了**；填好真实 `local.env` 后应无 `[STOP]` 才能上集群。

拿不准 → **框架 F1**（DIAMOND + eggNOG + InterProScan）。  
脚本顺序：`F1_diamond.sh` → `F2_eggnog.sh`（= F1 内步）→ `F3_interproscan.sh` → `F_merge_tables.py`（参数见 FAQ）。  
助手多半 print-first：`RUN=1` 才真正执行。

多 isoform 时先变成**每基因一条**再进 `PROTEINS_FA`（见 [FAQ_入门.md](FAQ_入门.md)）。

**交接：** `PROTEINS_FA` 优先指结构仓 `release/<TAG>/proteins.faa`（A6 稳定别名），不要默认抄结构 `WORK_DIR/proteins.faa` 可能过期的根副本。

植物常见：`EGGNOG_TAX_SCOPE=Viridiplantae`；`BUSCO_LINEAGE_PROTEIN` 与结构蛋白 QC 谱系对齐（如 `viridiplantae_odb12`（禾本科可用 poales_*，并与结构仓同一代 odb））。

## 为什么

1. 没有稳定 `proteins.faa`（带来源）就开跑 = 无 provenance。  
2. flow 先选框，避免 F2 快框冒充 F1。  
3. `local.env` 钉 DB 路径与谱系，复现靠它。  
4. Print-first（`RUN=1`）防止在错路径上烧 IPS。  
5. 拿不准 → **F1** 三件套。

**反例：** 复制同事的 Swiss-Prot 路径，实际指向过期或空文件。
